メニューの段階（①〜④）

    ④の先は、きつめの抵抗を＋1 → 早歩きを＋0.2km/h。

    NTCのプログラム（スタジオ開始後に追加）

    NTCはスタジオで使うアプリのため、スタジオ開始に合わせて追加します。追加後は以下の順番で指定します。

    プログラムの中の段階（ステージ）はNTCが進めます。AIRNIXが決めるのは「どのプログラムか」と「次へ進むか、もう1回か」だけです。

    初回の決め方
    • スタッフがお客様と一緒にトレッドミルで速さの基準を測定する
    • 1か月モニターで結果・満足度が最も高かった交代走法（早歩き⇔きつめ）から始める
    上げる・戻すの決まり
    • 楽だった → 1つ上げる
    • ちょうどよかった → そのまま
    • きつかった／痛みあり → 1つ戻す
    • 14日あいたら1つ軽く、28日あいたら①から
    • 最初の4回は、きつめの区間を入れない

    NTC（スタジオ開始後）

    • 来店ごとに「今週何回できたか」と「きつさ」を報告（1回の報告＝1週）
    • プログラムが終わったら、実施率70%以上で、きつい週が半分以下 → 次のプログラムへ
    • それ以外 → 同じプログラムをもう1回
    • 2週続けて0回 → 短いプログラム（毎日の運動チャレンジ 5〜10分）に切り替え
    • 痛み・体調の変化あり → NTCはお休みして同じ週をもう一度
