# 初回公開直後の確認リスト

公開した日に、**iPhone（Safari・AirNixアプリ）とAndroid（Chrome・AirNixアプリ）の実機**で行います。
確認用に「テスト」という名前で登録し、終わったら「記録をすべて削除する」で消します。
結果は □ に ✓ を付け、うまくいかなかった項目は画面の写真と一緒に担当者へ伝えます。

## 0. 公開の前に

- □ `npm run check`（型の確認）と `npm test`（決まりのテスト）が通っている
- □ `public/privacy.html` の制定日が入っている
- □ `STAFF_PASSWORD` を10文字以上で設定した
- □ `https://airnix-menu.pages.dev/` が開き、鍵マーク（https）が出ている

## 1. スタッフの画面（PCかスマホ）

- □ `/staff.html` で、お名前＋合言葉でログインできる。違う合言葉では入れない
- □ 「＋ 新しく登録」で「テスト」を登録でき、マイコードが出る
- □ 「文面をコピー」でコピーできる
- □ 一覧に「テスト」が出る。「まだ開いていません」と表示される
- □ ログアウトすると、もう一度合言葉が必要になる

## 2. お客様の画面（iPhone・Androidの両方）

- □ マイコードを入れてログインできる。違うコードでは「マイコードが違います」と出る
- □ 同意の画面が出る。チェックしないと進めない。「プライバシーポリシーを読む」から戻れる
- □ 今日のメニュー・NTC・食事・目標が表示される。文字や写真が欠けていない、横にはみ出していない
- □ 「NTCで開く」でNTCアプリ（入っていなければストア）が開く
- □ 「あすけんを開く」で、iPhoneはApp Store、AndroidはGoogle Playが開く
- □ あすけんの日数を押すと「記録しました」と出る
- □ 報告（楽だった・マシン・痛みなし）を送ると「今日の報告を受け付けました」と出て、もう一度は送れない
- □ 「今月の効果レポートを見る」が開き、「閉じる」で戻れる

## 3. 体調の確認の流れ

- □ 別のテスト登録で「痛みや体調の変化：あり」を送ると、確認の表示が画面の中に出る
- □ 送ったあと、お客様の画面に「スタッフが確認してから…」と出る
- □ スタッフの画面で、その方が赤い枠のカードでいちばん上に出る
- □ 「体調を確認した」を押すと、カードから消える

## 4. ログインが続くか（いちばん大事）

- □ AirNixアプリから開いてログイン → アプリを完全に終了（上にスワイプ）→ もう一度開くと、コードを入れずに表示される
- □ スマホを再起動しても、コードを入れずに表示される
- □ Safari・Chromeで開いた場合も同じように続く
- □ 翌日に開いても続いている

## 5. スタッフの操作

- □ 体重・ウエストの「測定を記録」が一覧に反映される
- □ 「マイコードを作り直す」で新しいコードが出る。お客様のスマホは前のコードでは入れなくなり、新しいコードで入れる
- □ 「利用終了にする」でお客様の画面が「ご利用が終了しています」になり、「利用終了」のタブに移る。「利用を再開する」で戻る
- □ 「記録をすべて削除する」で、お名前を違えて入れると止まり、正しく入れると消える

## 6. 圏外・そのほか

- □ 機内モードにすると「インターネットにつながっていません」と出て、戻すと消える
- □ スマホの文字を大きくする設定でも、ボタンが押せる
- □ ログアウト → 「もう一度開くときはマイコードが必要です」の確認が出る

## 7. 終わったら

- □ テストで作った方を「記録をすべて削除する」で消した
- □ Cloudflareの画面で、Functionsのエラーが出ていない（Workers & Pages → airnix-menu → ログ）
