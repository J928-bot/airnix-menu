# 個別メニュー スタッフの使い方（1ページ版）

スタッフの画面：`https://airnix-menu.pages.dev/staff.html`
はじめに、お名前と店舗の合言葉でログインします（12時間でログインが切れます）。
迷ったら、自分で判断せずに店長に相談してください。

## 1. 新しく登録する（初回の来店時）

1. 「＋ 新しく登録」を押します。
2. お名前・プラン（hacomonoと同じもの）・週の来店目標を選びます。
3. お客様と一緒にトレッドミルに乗り、「ゆっくり」と「早歩き」の速さを入れます。体重・ウエストを測った場合は、その数字も入れます。
4. 「登録してマイコードを発行」を押すと、マイコード（8文字）が出ます。
5. **その場で、お客様のスマホで一緒にコードを入れてください。** この画面を閉じると、コードは二度と表示できません。
6. 入れられなかったときは「文面をコピー」を押し、公式LINEで送ります。

## 2. 毎回の声かけ

- 画面は上から「すぐ対応 → 気にかける → 案内のタイミング」の順に並んでいます。上から順に対応してください。
- カードの枠の中の文章が、そのまま使える声かけです。
- 体重・ウエストは、来店直後・運動の前に測り、カードの欄に入れて「測定を記録」を押します。
- 「案内のタイミング」が出た方には、「効果レポート」を一緒に見ながら、カードの文章でご案内します。料金はhacomono・料金表で確認してください。案内したら「変更する」か「今は見送り」を押します。

## 3. 「体調の確認」が出たとき

- お客様が「痛みや体調の変化：あり」で報告すると、赤い枠のカードでいちばん上に出ます。その方の次のメニューは止まっています。
- 「その後、お体の具合はいかがですか？」と様子をうかがってください。
- 問題がなければ「体調を確認した（メニューを再開）」を押します。
- 気になる様子のとき、判断に迷うときは、押さずに店長に相談してください。

## 4. マイコードを忘れた・スマホを替えたとき

「そのほかの操作」→「マイコードを作り直す」を押します。新しいコードが出るので、1. と同じようにその場で一緒に入れてください。前のコードは使えなくなります。

## 5. 退会・休会のとき

「そのほかの操作」→「利用終了にする（退会など）」を押します。記録は残り、再開するときは「利用終了」のタブから「利用を再開する」を押します。利用終了から1年たつと、記録は自動で削除されます。

## 6. ご本人から「記録を消してほしい」と言われたとき

1. 「そのほかの操作」→「記録をすべて削除する」を押します。
2. 確認のため、お名前を登録どおりに入れて「削除する」を押します。
3. **元に戻せません。** ご本人からのお申し出のときだけ使い、削除したことを店長に伝えてください。

## やってはいけないこと

- マイコードや合言葉を、メモ・写真・LINEのグループに残さない
- マイコードの入ったアドレス（`?c=` が付いたもの）をLINEなどで送らない
- お客様の体調について、自分で「大丈夫です」と判断しない
